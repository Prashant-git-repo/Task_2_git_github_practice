# Task 2: Git & GitHub Fundamentals

## 📌 Overview
This project demonstrates hands-on practice of Git and GitHub fundamentals using an Ubuntu environment on an AWS EC2 instance.  
The task focuses on understanding real-world version control workflows followed in DevOps and software development teams.

---

## 🛠️ Tools & Technologies
- **Git** – Distributed Version Control System
- **GitHub** – Remote repository hosting
- **OS** – Ubuntu (AWS EC2 Instance)
- **Access Method** – SSH to EC2

---

## 🎯 Objectives
- Install and configure Git on Ubuntu
- Understand Git repository structure
- Track file changes and manage commits
- Connect local Git repository with GitHub
- Work with branches and merging

---

## 🚀 Steps Performed

1️⃣ **Git Installation & Configuration**
- Installed Git on Ubuntu EC2
- Configured global username and email


2️⃣ **Initialize Git Repository**
- git init
- git branch -m main


3️⃣ **File Tracking & Commits**
- git status
- git add .
- git commit -m "Initial commit"


4️⃣ **GitHub Integration**
- git remote add origin https://github.com/Prashant-git-repo/Task_2_git_github_practice.git
- git push -u origin main


5️⃣ **Branching & Merging**
- git checkout -b other-branch
- git merge other-branch
